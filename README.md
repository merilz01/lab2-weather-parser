# lab2-weather-parser
Лабораторная работа №2: Регулярные выражения. Unit-тестирование.

Описание
Программа извлекает данные о погоде (температуру, ветер, влажность, давление) из текста, файлов и веб-страниц с помощью регулярных выражений. Покрыта Unit-тестами.

Структура проекта
weather_parser.py - класс WeatherParser с регулярными выражениями
main.py - консольный интерфейс
test_weather_parser.py - Unit-тесты на корректный парсинг
test_errors.py - Unit-тесты на обработку ошибок

Как запустить
pip install requests
python main.py

Как запустить тесты
python -m unittest discover
